# The protocol lives in a sans-IO core package

The whole protocol is written in a separate core package that uses no Bun or Node API, never reads the clock and never arms a timer: Datagrams and the passage of time are handed to it, and it hands back Datagrams to send and events. The server and client packages are thin adapters binding it to `Bun.udpSocket` and real timers. We chose this over writing the protocol directly against Bun because it makes every behavior testable deterministically on a simulated network with a manual Clock (a ten-second timeout test runs instantly and replays from a seed), and because a future browser Transport can reuse the core unchanged. The cost is an extra package and an explicit Transport and Clock interface; core's type configuration excludes Bun and Node types so the boundary is enforced by the type-checker rather than by discipline.
